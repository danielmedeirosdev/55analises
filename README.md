## O site

Uma apresentação da agência com identidade em rosa, preto e branco, imagens integradas e navegação responsiva.

- **Cases de sucesso:** campanhas com detalhes da atuação, votação, resultado e fonte.
- **Serviços:** carrossel com navegação por toque, setas e teclado.
- **FAQ:** respostas sobre atendimento, serviços e contratação.
- **Contato:** acesso direto à equipe por WhatsApp e e-mail.

## Desenvolvimento

Construído com **HTML, CSS e JavaScript**, com hospedagem na **Vercel**. Sem etapa de build ou instalação de dependências.

Para executar localmente, sirva a pasta do projeto com um servidor HTTP:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.

| Arquivo | Função |
| --- | --- |
| `index.html` | Estrutura e conteúdo |
| `style.css` | Identidade visual e layout responsivo |
| `app.js` | Cases, diálogos, menu e carrossel |
| `assets/` | Imagens do site |
| `vercel.json` | Configuração de hospedagem |
